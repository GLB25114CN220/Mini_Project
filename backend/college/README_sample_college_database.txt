SAMPLE COLLEGE STUDENT DATABASE
================================
This package contains fictional sample student data, not real student records from any college.

Files:
- sample_college_students.csv — CSV import
- sample_college_students.xlsx — Excel spreadsheet
- sample_college_students.sqlite — SQLite database with a students table
- sample_college_students.sql — SQL schema and insert statements

Columns: student_name, branch_code, branch_name, section, roll_number, admission_id, academic_year.
Contains 96 fictional sample students across six branches and sections A/B.
Admission IDs use the format ADM-2026-XXXX.
